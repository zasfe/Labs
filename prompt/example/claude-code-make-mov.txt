일단, AI에게 상품을 그리게 하지 않는 것이 중요한데요, 
실제 상품 사진을 그대로 쓰고, 클로드에게는 그 사진을 움직이는 일만 맡겨야 합니다. 

- 상품 사진이 몇개 정도 준비되어있는지 모르겠지만, 상품 사진이 각도별로 준비하면 좋습니다. (정면, 옆면, 뒷면처럼 5~8장 정도면 되고, 배경을 지운 PNG가 좋습니다)

- 클로드코드에서 HyperFrames라는 오픈소스 도구를 활용해서 작업하라고 하고, 사진을 주고 '이 사진들로 15초 상품 소개 영상을 만들어줘. 사진은 수정하지 말고 확대, 이동, 장면 전환, 자막만 넣어줘'라고 요청을 함 해보세요 

(저는 '장면은 사진 한 장에 2~3초씩 /  전체 모습 → 확대 → 뒷면 → 빠른 컷 → 로고 순서로 6장면을 만들어줘')
이런 식으로 프롬프트에 포함하기도 합니다. 

대신 사진에 없는 각도나 상품이 실제로 회전하는 장면은 만들 수 없어요. 
(그런 장면이 필요할 때만 영상 생성 AI를 쓰고, 그때도 상품 사진을 시작 이미지로 넣어주세요 / 안그러면 다른 각도 사진 만들면서 맘대로 바꾸고 그럽니다..ㅎㅎ)
