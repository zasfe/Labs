아래 프롬프트에 설명받고 싶은 주제나 자료를 넣어 사용하면 됩니다.

아래 주제 또는 자료를 이해하기 위한 HTML 설명 파일을 만들어줘.

주제 또는 자료:
[여기에 주제, 문서, URL 또는 코드 경로 입력]

목적:
내용을 처음 읽는 사람이 핵심 개념과 관계를 이해하고,
필요한 세부 내용을 쉽게 찾아볼 수 있게 해줘.

작성 기준:
- 제공한 자료를 먼저 확인하고, 원문에 없는 사실이나 의도를 만들어내지 마.
- 핵심 요약 → 주요 내용 → 세부 설명 순서로 구성해줘.
- 내용에 맞게 표, 흐름도, 비교 화면 등을 사용하되 불필요한 장식은 넣지 마.
- 긴 세부 내용은 접어서 펼칠 수 있게 하고, 주요 항목으로 이동할 수 있는 목차를 넣어줘.
- 출처와 확인하지 못한 내용은 구분해서 표시해줘.
- 본문은 한국어로 작성하되 코드와 고유한 기술 명칭은 유지해줘.

파일 조건:
- 브라우저에서 바로 열 수 있는 단일 HTML 파일로 만들어줘.
- CSS와 필요한 JavaScript는 파일 안에 포함해줘.
- 외부 라이브러리, CDN, 외부 글꼴 없이 작동하게 해줘.
- 모바일과 PC에서 모두 읽기 편하게 만들어줘.
- 상호작용은 이해에 도움이 되는 경우에만 추가해줘.

완료 조건:
- 개요나 코드 조각이 아니라 완성된 HTML 파일을 제공해줘.
- 가능하면 브라우저에서 열어 레이아웃과 목차·접기 기능을 확인해줘.
- 직접 확인하지 못한 부분은 명확하게 알려줘.


단일 파일·외부 의존성 제외·동작 확인 조건은 처음 사용하기 편하도록 추가한 조건이며, 원문이 정한 필수 규칙은 아닙니다.
